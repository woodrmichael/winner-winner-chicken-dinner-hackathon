# Map data and design references

| Asset | Source and maintenance notes |
| --- | --- |
| Milwaukee street map | [OpenFreeMap Liberty](https://openfreemap.org/quick_start/) displays OpenStreetMap data through MapLibre. The basemap loads over the internet. The renderer loads its matching version of the MapLibre worker from jsDelivr. The map’s credits link to the data providers. |
| Neighborhood outlines | [City of Milwaukee DCD and ITMD-GIS, neighborhood layer 0](https://milwaukeemaps.milwaukee.gov/arcgis/rest/services/AGO/neighborhoods/MapServer/0). The [bundled GeoJSON](../src/features/map/neighborhoods.geojson.json) includes all 190 features. Query `where=1=1`, `outFields=NEIGHBORHD`, `outSR=4326`, `geometryPrecision=5`, `maxAllowableOffset=0.00015` and `f=geojson`. Convert the City name to title case and store it as `area`, with Brewer’s Hill normalized to Brewers Hill for existing workspace records. |
| Public libraries | [City of Milwaukee Library Services GIS](https://milwaukeemaps.milwaukee.gov/arcgis/rest/services/AGO/LibraryServices/MapServer/0). The [bundled locations](../src/features/map/libraries.json) provide an initial snapshot. The API and local device cache refresh from the city feed after 24 hours. The importer corrects the old 310 W. Locust St. record with the King branch address and coordinates from [Milwaukee Public Library locations and hours](https://mpl.org/hours_locations/), also linked from each pin. |
| Community event venues | The [initial event records](../src/domain/demoCommunity.ts) use public meeting points from [Milwaukee County Parks](https://county.milwaukee.gov/EN/Parks/Explore/Find-a-Park) and [Milwaukee Public Library](https://www.mpl.org/hours_locations/). The [bundled venue previews](../assets/venue-maps/) render OpenFreeMap Liberty at those coordinates and show the map credits in the event card. |
| Homicides and nonfatal shootings | [MHRC 2016 annual report, appendix tables 16–17](https://city.milwaukee.gov/ImageLibrary/Groups/healthAuthors/OVP/Reports/2016MHRCAnnualReport9-29-2017FINAL.pdf). The [incident series](../src/domain/seed.ts) uses 2014–2016 neighborhood totals. Update the map’s period and attribution whenever you replace this series. |
| Winter drive photo | [Original image](https://images.unsplash.com/photo-1445205170230-053b83016050) · [Unsplash license](https://unsplash.com/license) |
| ComForce MKE mark | The app displays the green mark from the [official website’s header logo](https://www.comforcemilwaukee.com/assets/homepage/regenerated/brand-logo-header.png). |

The [initial workspace records](../src/domain/seed.ts) provide sample referrals, events and participation for reproducible walkthroughs. Service activity and event schedules in those records are fictional. The library locations and neighborhood boundaries come from the public sources above.

The [MHRC dashboards](https://www.mcw.edu/departments/epidemiology/research/milwaukee-homicide-review-commission/reports/dashboards) publish newer homicide and nonfatal shooting figures. Import a newer series only when both measures are available at the same neighborhood boundaries and reporting period. The [IMPACT 211 directory](https://www.impactinc.org/impact-211/) is a public resource lookup. A referral integration requires an agreed directory feed and participating providers.
